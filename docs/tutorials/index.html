SpaceRec / Tutorial

Existing Visium data tutorial

Run SpaceRec on BRCA Visium counts, H&E imaging, and a single-cell reference to generate dense grid-level cell-type and expression maps.

Setup

Work from an allocated Slurm compute node. Use a GPU for full image embedding and both training stages. Activate the existing Python environment and point SpaceRec to the separate R environment used by RCTD. 

cd SpaceRec
conda activate spacerec_env
export SPACEREC_R_ENV="$HOME/.conda/envs/spacerec_r_env"

python -c "import spacerec.api as spacerec; print(spacerec.__file__)"
python -c "import torch; print(torch.cuda.is_available())"
"$SPACEREC_R_ENV/bin/Rscript" -e "library(Matrix); library(Seurat); library(spacexr); library(hdf5r)"
The notebook can recover GPU indices from the active Slurm allocation when CUDA_VISIBLE_DEVICES is absent. It does not submit a new allocation by itself.

Quick start

Main notebook spacerec/notebooks/spacerec.ipynb
Dataset dataset = "brca", sample_id = "BREAST"
Input and output root resources/brca/

Open spacerec.ipynb, select the spacerec_env kernel, and run the cells in order. Stage 2 is restart-safe after Stage 1 because it reconstructs every required path from disk.

Workflow

  1. Validate supplied deconvolution proportions and build the RCTD expression reference.
  2. Extract dense Virchow2 H&E features and create the H&E tissue mask.
  3. Train the Stage 1 router and grid cell-type model.
  4. Train the Stage 2 expression model from the Stage 1 checkpoint.
  5. Inspect grid-level type and expression predictions in an editable bbox.

Step 1: deconvolution and expression reference

The notebook reuses deconv/deconv.csv only after validating barcode identity, finite nonnegative values, and row sums. It rebuilds the ordered 11-cell-type expression prior from the single-cell reference and real Visium gene space.

\[x_s \approx l_s\sum_k p_{s,k}r_k, \qquad p_{s,k}\ge 0, \qquad \sum_k p_{s,k}=1\]
rctd_ref_summary = spacerec.rctd_ref(
    dataset="brca",
    sc_ref_h5ad=sc_ref_h5ad,
    synthetic_h5=visium_h5,
    positions_csv=positions_csv,
    output_dir=rctd_ref_dir,
    gene_list_txt=gene_list,
    merge_json=brca_merge_json,
    force=True,
)

Step 2: grid embedding and H&E mask

The current configuration uses a 480px patch and 120px stride. It concatenates the 1280-dimensional Virchow2 class token with 2560 local tile features and leaves neighbor features disabled.

\[h_g=[t_g;u_g]\in\mathbb{R}^{3840}\]
ge_summary = spacerec.ge(
    dataset="brca",
    he_image=he_image,
    positions_csv=positions_csv,
    scalefactors_json=scalefactors_json,
    thumbnail_png=thumbnail_png,
    output_dir=embedding_dir,
    patch_size=480,
    stride=120,
    concat_local=True,
    concat_nbr=False,
    model="virchow2",
    batch_size=4,
    force=True,
)

spacerec.mask(...) then removes background grids and writes embedding/grid_embedding_train_filtered.h5 for training.

Step 3.1: router and cell-type model

Stage 1 predicts a cell-type probability vector for every retained 30px grid. Grid probabilities are averaged inside each Visium spot for supervision.

\[\hat{p}_s=\frac{1}{|G_s|}\sum_{g\in G_s}\hat{q}_g\]
stage1_summary = spacerec.stage1(
    dataset="brca",
    st_h5ad=visium_h5,
    deconv_csv=deconv_csv,
    grid_embedding_h5=training_grid_embedding_h5,
    gene_list=gene_list,
    mu_ref=mu_ref,
    run_dir=train_dir,
    projection_dim=2048,
    batch_size=4,
    stage1_epochs=70,
    agg=False,
)

Outputs are the Stage 1 checkpoint and grid-level type probabilities. No polygon or cell aggregation runs in this stage.

Step 3.2: expression model

Stage 2 loads the Stage 1 checkpoint and predicts nonnegative grid expression. Grid values are summed to Visium spots for expression supervision.

\[\hat{x}_s=\sum_{g\in G_s}\hat{x}_g\]
\[\mathcal{L}_{expr}=\operatorname{Huber}(\log(1+\hat{x}_s),\log(1+x_s))\]
stage2_summary = spacerec.stage2(
    dataset="brca",
    st_h5ad=visium_h5,
    deconv_csv=deconv_csv,
    grid_embedding_h5=training_grid_embedding_h5,
    stage1_checkpoint=stage1_checkpoint,
    gene_txt=gene_list,
    mu_ref=mu_ref,
    run_dir=train_dir,
    projection_dim=2048,
    batch_size=4,
    stage2_epochs=70,
    agg=False,
)

Stage 2 writes its checkpoint, grid_predictions.h5, grid_type.csv, and grid_expr.h5ad. Cell-level aggregation remains separate.

Step 4: inspect a spatial bbox

Set bbox_xyxy=(x0,y0,x1,y1) in full-resolution H&E coordinates and choose one gene. The notebook renders matching grid-level type and expression panels without changing their spatial aspect ratio. 

type_plot = spacerec.plottype(
    dataset="brca",
    grid_type_csv=train_dir / "grid_type.csv",
    window=bbox_xyxy,
    output_dir=grid_window_dir,
)

expr_plot = spacerec.plotexpr(
    dataset="brca",
    grid_expr_h5ad=train_dir / "grid_expr.h5ad",
    window=bbox_xyxy,
    output_dir=grid_window_dir,
    gene="KRT5",
)

Each gene is standardized within its own bbox and clipped to the displayed range.

\[z_g=\operatorname{clip}\left(\frac{x_g-\mu_{bbox}}{\sigma_{bbox}},-2,2\right)\]

Optional cell aggregation

Cell-level aggregation is not part of either training stage in the main existing-data notebook. Run it separately only when a polygon file is available. 

aggregate_summary = spacerec.agg(
    dataset="brca",
    grid_expr_h5ad=train_dir / "grid_expr.h5ad",
    grid_type_csv=train_dir / "grid_type.csv",
    grid_predictions_h5=train_dir / "grid_predictions.h5",
    polygon_csv=polygon_csv,
    output_dir=aggregate_dir,
)
