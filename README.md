# SpaceRec GitHub Pages

The mouse cerebellum C2/C3 comparison visualizer is published at both the
repository root and the stable `cerebellum/` subpath:

`https://spacerecproject.github.io/SpaceRec/cerebellum/`

- DAPI-only base image from OME channel 1
- masked 30 px SpaceRec Stage 1 eight-class grid prediction
- swipe, opacity, side-by-side, sample switching, and PNG export
- no expression view or expression assets

The earlier Owkin visualizer remains available under `owkin/`.
